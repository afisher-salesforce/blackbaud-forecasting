# Blackbaud Forecasting Website

Executive-ready discussion site for Blackbaud forecasting strategy across two value streams:

- A2R (Awareness-to-Revenue)
- I2R (Implementation-to-Renewal)

## Purpose

Support Salesforce account team pre-sales conversations to prioritize native Salesforce capabilities that can retire Clari and Gong while preserving execution in the sales and renewals flow of work.

## Local preview

Open `index.html` directly in a browser, or run any lightweight static server from this directory.

- `index.html` - Executive Summary
- `context.html` - Account Context
- `a2r-capabilities.html` - Awareness-to-Revenue (A2R)
- `i2r-capabilities.html` - Implementation-to-Renewal (I2R)
- `capability-map.html` - Capability Sequencing
